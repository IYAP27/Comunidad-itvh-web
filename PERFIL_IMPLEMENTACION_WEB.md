# Perfil de usuario web — v1

Esta versión completa varios huecos que quedaban frente a la app móvil:

- Perfil propio y perfil público con publicaciones, bio, carrera/semestre, redes e insignias.
- Edición de perfil ya existente: nombre, usuario, presentación, carrera, semestre, redes y foto.
- Botón de Ajustes funcional desde Mi Perfil.
- Botón Mensaje funcional desde perfiles públicos, abre JaguarChat con el usuario seleccionado.
- Listas de Seguidores y Seguidos con búsqueda y acceso al perfil de cada usuario.
- Contador de seguidores se actualiza al seguir/dejar de seguir.
- Historias destacadas ahora se pueden abrir desde el perfil y usan el visor web de historias.
- Diseño responsive para la hoja de seguidores/seguidos.

## Pruebas recomendadas

1. Abrir Mi Perfil y Editar perfil.
2. Abrir Seguidores y Seguidos y usar el buscador.
3. Abrir un perfil público y pulsar Seguir / Siguiendo.
4. Pulsar Mensaje y comprobar que abre JaguarChat.
5. Abrir una historia destacada.
6. Pulsar el engrane de Mi Perfil y comprobar que abre Ajustes.
